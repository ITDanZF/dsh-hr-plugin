# client

DeepSeek Harness 网页上的简历界面写在这一层。左侧对话保持 Harness 原页面；本层只加右侧简历面板。

## 职责

- 入口 `index.tsx` 向 `ctx.sidebarRightTabs` 注册 kind `resume`。安装后不打开右侧栏。
- 右侧「开始」页放一张「简历」卡片。点击后展开右栏。同一会话只有一个简历页。
- 编辑和模板只在简历页顶栏切换。刚打开停在编辑的板块列表。切到模板再回到编辑时，停在刚才打开的那一块。
- 有会话 id 时，面板通过 `http://127.0.0.1:3091` 读取和保存。会话 id 来自属性，或外层的 `data-sidebar-right-session`。本地有未保存修改时，轮询不覆盖。
- 没有会话 id 的 Vite 预览使用示例草稿，不请求预览接口。
- 顶栏「导出」只打印当前纸面。左侧对话不打开面板。

## 依赖

- 允许：宿主 UI 槽位，以及领域层的文档类型。
- 禁止：直接写 SQLite。

## 联调

- `pnpm run dev:panel` 打开 `http://127.0.0.1:5174/`。改界面可以热更新。
- 放进 Harness 仍要重新编译客户端并重启 `hr-dev`。
