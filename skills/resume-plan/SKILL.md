# 简历任务入口

本插件一个会话保存一份简历。收到实际处理简历的请求时：

1. 本轮尚未读过说明书，就调用 `resume_read_manual` 并阅读 `manual`。
2. 本轮尚未读过工作流，就调用 `resume_read_workflow` 并阅读 `workflow`。
3. 按 `resume-workflow` 的正文处理。不要凭工具名猜测参数或绕过分类技能。

读取工具返回 `ok: false` 时，告知用户返回的 `error`，停止依赖该结果的操作。用户只是询问写法、评价现有内容或索要建议时，可以给出分析；未经请求，不把建议写入简历。
