# 导出简历

只在用户明确要求导出、下载或生成文件时使用。若还要求修改正文或纸面，先完成修改，确认最新 `document`，再导出。

`resume_export_pdf` 会生成支持中文和自动换页的 PDF，并应用基本字体大小、颜色和疏密；它不完整复现右侧的侧栏、照片等纸面布局。需要文件且可接受这种排版时调用一次，检查结果后提供 `path`。`ok: false` 时告知返回的 `error`，不要假称已生成文件。缺少中文字体时需要在宿主机器上设置 `DSH_HR_PDF_FONT` 指向支持中文的 TTF 或 OTF 文件。

用户要精确保留照片、侧栏或当前页面样式时，请其在右侧简历页使用「导出」打印/保存为 PDF。这条路径由浏览器的打印功能完成；不要声称已替用户下载、打印或验证页面效果。
