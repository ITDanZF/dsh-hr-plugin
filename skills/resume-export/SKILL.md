# 导出简历

只在用户明确要求导出、下载或生成文件时使用。若还要求修改正文或纸面，先完成修改，确认最新 `document`，再导出。

`resume_export_pdf` 与右侧「下载 PDF」使用同一份支持中文和自动换页的排版，按当前模板绘制侧栏、页顶色条、页眉、日期和关键词。启用照片时包含 PNG/JPEG 照片。需要文件时调用一次，检查结果后提供 `path`。`ok: false` 时告知返回的 `error`，不要假称已生成文件。缺少中文字体时需要在宿主机器上设置 `DSH_HR_PDF_FONT` 指向支持中文的 TTF 或 OTF 文件。找不到对应字体时会改用通用中文字体。

「打印当前样式」由浏览器打印完成，版式更接近屏幕像素。不要声称已替用户下载、打印或验证页面效果。
